Telefona kur

  1. Bu sayfayı telefonunda Chrome veya başka bir tarayıcıyla aç.
  2. APK indir düğmesine bas. Tarayıcı indirmeyi engellerse ZIP seçeneğini kullan; ZIP'i açıp içindeki APK'ya dokun.
  3. İndirilenler bölümünden APK'yı aç. Android isterse tarayıcına veya dosya uygulamana bu kaynaktan yükleme izni ver.
  4. Alzirr'i aç. Yeni model yanıtları için Bağlantılar ekranına kendi sağlayıcı anahtarını ekle.

Kayıtlı çalışmalar çevrimdışı açılır. Yeni model yanıtları internet ve sağlayıcı API anahtarı ister. Bulut eşitlemesi isteğe bağlıdır. Bu önizlemede telefon yürütmesi uygulama görünürken çalışır.

English · Install instructions

Download the signed APK using the first button. If your browser blocks APK downloads, use the ZIP button and extract the APK.

Android 8+. Open the downloaded APK and allow installation from your browser or file app when Android asks. No GitHub or Alzirr account is required.

Saved work is available offline. New model responses need internet and your own provider API key. Cloud sync is optional; phone execution runs while the app is visible.
